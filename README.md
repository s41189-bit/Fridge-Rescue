
# Fridge Rescue
智慧冰箱剩食推薦與保鮮管家

目前版本：A 版 V1.1

## 一、專案介紹

本網站以「先看冰箱，再決定料理」為核心概念，
透過現有食材進行料理推薦、智慧補貨及採買決策，
降低下廚的決策成本並減少食物浪費。

目前版本為組員 A 的 V1.1 核心功能開發版，
已完成 P0 核心功能及 P1 料理抽籤機，
並支援個人冰箱食材記錄與實際使用。

尚未整合組員 B 與 C 的正式成果。

### 料理抽籤機

使用者可點擊「幫我抽一道料理」，
從目前符合篩選條件的食譜中隨機選擇一道。

抽籤條件與原有食譜推薦保持一致：

- 料理時間
- 料理難度
- 飲食偏好
- 零採買模式
- 目前冰箱庫存

抽籤結果直接使用原有食譜詳情視窗。

若沒有符合條件的料理，系統會顯示提示。

## 五、操作方式

### 個人冰箱使用

1. 開啟 index.html 或 GitHub Pages 網站。
2. 選擇自己冰箱中實際擁有的食材。
3. 設定食材到期日。
4. 點擊「新增食材」。
5. 查看食譜推薦及匹配度。
6. 切換料理篩選與零採買模式。
7. 使用料理抽籤機。
8. 查看智慧補貨推薦。
9. 將缺少食材加入採買清單。
10. 勾選、刪除或複製採買清單。
11. 重新整理網頁，確認資料保留。

### 示範模式

點擊「載入示範資料」，即可快速載入：

- 番茄
- 雞蛋
- 吐司

適合課堂展示與功能測試。

若目前已有庫存，系統會要求確認是否取代。
取消操作則不修改原本庫存。

### 保存期限提醒

| 燈號 | 剩餘期限 | 配對規則 |
|---|---|---|
| 綠燈 | 4 天以上 | 正常參與配對 |
| 黃燈 | 0–3 天 | 優先推薦 |
| 紅燈 | 已逾期 | 排除該筆庫存 |
| 灰色 | 未設定日期 | 正常參與配對 |

### 本機資料保存說明

冰箱庫存與採買清單使用 localStorage 保存。

- 不需要登入或註冊。
- 資料保存在目前裝置及瀏覽器的網站儲存空間。
- 不同裝置與瀏覽器不會自動同步。
- 清除瀏覽器網站資料可能導致紀錄消失。
- 共用相同瀏覽器設定檔及網站的使用者可能共用資料。
- 本機 index.html 的資料不會自動同步至 GitHub Pages。
- 個人冰箱資料不會因 localStorage 而上傳至 GitHub。

目前保留原有 localStorage key：

- fridgeRescue_A_mock_v1
- fridgeRescue_A_shopping_v1

Bootstrap 使用 CDN，需要網路連線。
本機資料保存與複製功能可能受瀏覽器設定影響。
